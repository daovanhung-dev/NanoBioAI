# Assets — full-project-2026-07-28

Thư mục này chứa ảnh PNG **mới** từ campaign này sau khi đã kiểm tra trực quan
và redact. Khi tạo file README này chưa có asset nào được ghi nhận.

## Quy tắc đặt tên

```text
<CASE-ID>--<surface-hoac-state>--<YYYYMMDD-HHMMSS>.png
```

Ví dụ tên chỉ để minh họa: `PF-028--sale-overview--YYYYMMDD-HHMMSS.png`.
Tên file phải được liên kết từ evidence case tương ứng.

## Quy tắc an toàn

- Chỉ giữ ảnh thể hiện kết quả người dùng nhìn thấy và đã được kiểm tra trước
  khi ghi vào evidence.
- Không ghi mật khẩu, token, email/định danh không cần thiết, dữ liệu sức khỏe,
  ảnh proof nguyên gốc, số tiền/số dư nhạy cảm hoặc thông tin hệ thống.
- Redact trước khi đặt ảnh vào thư mục này; nếu không thể redact an toàn, ghi
  mô tả evidence kỹ thuật tối thiểu trong file case thay vì lưu ảnh.
- Không dùng lại screenshot từ campaign cũ và không đổi tên ảnh cũ để làm
  evidence mới.
- Một screenshot không thay thế evidence kỹ thuật cho RLS, race, idempotency,
  ledger, quota hoặc retry.
