# NBI-005 — Map 365 locked

## Persona and preconditions

`FREE-READY` reaches the locked Map 365 condition. M30 catalog content exists,
but the unified runtime has no M30 trigger/render integration.

## Steps

1. Audit the active entry point and M30 provider use sites.
2. Audit the M30 app shell and CTA navigation adapter.
3. Determine whether a locked Map 365 condition can cause a real notification.

## Expected

The notification appears only for the eligible actor and its CTA must not grant
an incorrect entitlement or route.

## Actual and decision

No active M30 controller or overlay receives the condition; default navigation
is a no-op. No eligible user can see or activate this notification. Recorded
**FAIL**.
