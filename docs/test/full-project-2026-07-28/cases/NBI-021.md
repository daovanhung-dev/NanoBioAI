# NBI-021 — Concurrent trigger priority, suppression and cooldown

## Persona and preconditions

`FREE-EXHAUSTED` with multiple theoretical notification triggers. No concurrent
fixture events were fabricated because the production M30 event source is not
integrated.

## Steps

1. Inspect the engine/controller implementation and its reachable callers.
2. Inspect unified startup and mounted app shell.
3. Determine whether any concurrent business events can invoke the engine in
   the active runtime.

## Expected

Exactly the permitted high-priority notification appears, with global
suppression/cooldown preventing an excessive or duplicate sequence.

## Actual and decision

Although an isolated engine exists, no active runtime caller invokes it.
Concurrent production events cannot reach priority/suppression/cooldown or a
user-visible surface. Recorded **FAIL**.

See `technical/NBI-M30-runtime-audit.md` and the linked M30 finding.
