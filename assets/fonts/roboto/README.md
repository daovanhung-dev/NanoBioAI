# Bundled Roboto

NanoBio bundles four deterministic Roboto instances for UI and golden tests:
400, 500, 600 and 700.

- Upstream: `googlefonts/roboto-3-classic`, release `v3.016`
- Source asset: `web/split/Roboto[wdth,wght].ttf`
- Source release: https://github.com/googlefonts/roboto-3-classic/releases/tag/v3.016
- License: SIL Open Font License 1.1, copied in `OFL.txt`
- Generation: static instances produced with fontTools `varLib.instancer` at
  `wdth=100` and the declared `wght` value. No outlines or naming data were
  edited by hand.
