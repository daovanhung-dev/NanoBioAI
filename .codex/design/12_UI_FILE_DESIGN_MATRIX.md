## Column rules

- `Current evidence`: bằng chứng static, không phải đánh giá runtime PASS.
- `Target design`: yêu cầu thiết kế cụ thể của file.
- `Feedback`: mọi sound/haptic phải qua service.
- `Performance`: giới hạn bắt buộc.
- `Wave`: thứ tự coding, không phải commit cứng.
