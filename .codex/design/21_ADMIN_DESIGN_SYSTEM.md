# Admin Design System

Admin has no Stitch reference. It uses the shared Blue Wellness semantic foundation and component states with operational density, strong alignment, responsive sidebar/workspace, persistent filters where useful, explicit permission-denied states and confirmation dialogs for mutations.

Monetary and status columns remain aligned and scannable. No ambient Nabi; sound is Off by default. Admin shares semantic color, typography, focus, keyboard, dark-mode and reduced-motion roles; layout density and operational hierarchy remain specific to the workspace.
