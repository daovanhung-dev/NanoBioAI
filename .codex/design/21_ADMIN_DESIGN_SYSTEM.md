# Admin Design System

Admin has no Stitch reference and is not redesigned as Green Wellness. Preserve its independent operational workspace theme, high information density, strong alignment, responsive sidebar/workspace, persistent filters where useful, explicit permission-denied states and confirmation dialogs for mutations.

Admin adopts only shared Roboto typography, semantic accessibility, focus visibility, keyboard support, deterministic dark-mode compatibility and reduced-motion behavior. Monetary and status columns remain aligned and scannable. No ambient Nabi; sound is Off by default. Consumer Green tokens must not recolor Admin merely through a global facade.
