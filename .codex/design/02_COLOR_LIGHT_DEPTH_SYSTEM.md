# Color, Light & Depth System

Use semantic token families instead of raw colors. Primary/action blue communicates direction; cyan communicates information/tracking; mint communicates verified positive completion; amber communicates caution; red communicates actionable error; violet is reserved for AI/premium differentiation.

Content surfaces should be opaque/tonal. Translucency is limited to floating navigation or transient control layers and must remain readable when transparency is reduced. Depth comes from tonal separation, 1 px semantic borders and short soft shadows—not stacked blur.
